口径说明
1. 下店：商户「审核通过时间（开店时间）= 当日」且为考核商户（考核_是否考核商户 = 1）的商户数，按 shop_id 去重。另列「其中餐饮考核」＝考核餐饮_是否餐饮考核商户 = 1。下店是新签得分的前提，没有下店就没有得分。注意：「当日下店」= 当天新开店的考核商户家数（当日增量），不是截至当天的累计；「近7天 / 近3天 / 月累计」才是累加口径，四者并列展示、互不替代。
2. 新签得分：0.5×常规新签加权系数 + 0.5×战略新签加权系数，仅统计业务线 = FML 且「是否已记录绩效 = 1」的商户；按月累计，上月遗留记分计入月初基数。
3. 月累计达成率 = 0.5×(常规累计达成 ÷ 常规目标) + 0.5×(战略累计达成 ÷ 战略目标)，不折算时间；日维度达成率 = 单项完成率 × 31 ÷ 已过天数后单项封顶 100% 再加权（与官方考核口径一致，城市级与官方「餐饮新签完成率」逐城一致），d = 14。
4. 时间进度 = 已过天数 ÷ 月天数 = 14/31 = 45.2%。缺口 = 月累计达成率 − 时间进度，正数领先、负数落后。
5. BDM / BD 不设目标：官方目标只下发到城市级，BDM / BD 无目标，因此**不计算达成率**，只展示达成值（常规/战略达成、累计得分、下店量），名次按累计得分排名。
5.1 每日得分：① 当日新增分 = 当日新开店记分商户的（0.5×常规加权系数 + 0.5×战略加权系数）之和，是纯增量；② 日维度得分 = 该日官方「餐饮新签得分」（= 日维度达成率 × 100 × 过程项系数），城市级取官方值，整商 = 9 城得分加总。
5.2 每日下店：见第 1 条——开店日 = 当日且为考核商户的家数，是当日增量，与累计口径并列展示。
6. 数据源：ARK「城代新签考核--商户粒度」(2026-10-14) + 「城市月度考核--2610起」餐饮过程表（官方目标 / 完成率 / 得分）。城市级日维度达成率与官方值逐城一致。
7. 开化本月战略/常规新签目标均为 0，不参与考核；津市战略目标为 0。
